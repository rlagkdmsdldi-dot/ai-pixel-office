# AI 픽셀 오피스 🏢

**내 일을 도와주는 AI 직원들이 일하는 작은 사무실이에요.**

필요한 직원을 뽑아서 일을 맡기면,
직원들이 일정과 메일을 보고 정리해서 보고해 줘요.
화면 속 직원들은 실제로 걸어 다니고, 회의도 하고, 수다도 떨어요.

> 실제로 매일 쓰던 사무실을 개인 정보를 모두 빼고, 누구나 쓸 수 있게 공개했어요.

## 이런 걸 할 수 있어요

| | |
|---|---|
| 👥 **직원 뽑기** | 26명 후보 중에서 필요한 직원만 골라요. "회사원", "블로그 운영"처럼 추천 묶음도 있어요. |
| 🤖 **일 맡기기** | 직원에게 "매주 월요일 9시에 이번 주 일정 정리해줘"처럼 한 줄로 쓰면 그대로 해요. |
| 📅 **구글 연결** | 내 구글 캘린더, Gmail, 구글 드라이브를 읽어서 정리해요. (읽기만 해요) |

| 💬 **지시창** | "금요일까지 보고서" 하고 쓰면 담당 직원이 일정과 할 일로 등록해요. |

**직원 팀:** 회사 · 대학원 · 가정(가계부·장보기) · 자기계발(자격증·운동·독서) · 블로그 · N잡(강의·부업)

## 시작하기 (5분)

> 필요한 것: **claude.ai 계정** (이 사무실은 Claude 안에서만 움직여요)

**1. 파일 받기**
위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기

**2. Claude에 올리기**
claude.ai에서 새 대화를 열고 `index.html`과 `capabilities.json` 두 파일을 첨부한 뒤 이렇게 보내세요.

```
이 HTML을 아티팩트로 그대로 게시해줘. capabilities는 첨부한 capabilities.json대로 선언해줘.
```

**3. 직원 뽑기**
만들어진 사무실을 열면 **직원 채용** 창이 떠요. 필요한 직원을 고르고 **채용하기**를 누르세요.

**4. 일 맡기기**
직원을 눌러 **업무 자동화** 칸에 맡길 일을 한 줄로 쓰세요. 예시 문장을 눌러도 돼요.

끝! 이제 사무실을 열 때마다 직원들이 맡은 일을 해서 보고해요.

## 처음 쓸 때 뜨는 "허용" 창

사무실이 처음 어떤 기능을 쓸 때 **허용할까요?** 창이 떠요. 눌러 주셔야 그 기능이 켜져요.

| 창이 뜨는 때 | 무엇을 허용하는 건가요 |
|---|---|
| 직원에게 일을 시킬 때 | 직원이 Claude로 글을 읽고 정리하는 것 |
| **구글 연결** 버튼을 누를 때 | 구글 캘린더·Gmail·드라이브를 **읽는** 것 |

- 구글 서비스는 먼저 **claude.ai 설정 → 커넥터**에서 연결해 두어야 해요.
- 사무실 위쪽 **구글 연결** 버튼으로 잘 연결됐는지 확인할 수 있어요.
- 허용한 것은 사무실 화면의 권한 메뉴에서 언제든 끌 수 있어요.

**직원들이 절대 하지 않는 것:** 메일 보내기·지우기, 일정 바꾸기, 결제, 글 발행

## 자주 묻는 것

**Q. 직원들은 언제 일하나요?**
정해진 시각이 지난 뒤 사무실을 열면 그때 일하고 보고해요.
창을 닫아 둬도 그 시각에 일하게 하려면, 직원 카드의 **예약 작업 문장 복사**를 눌러 Claude 앱의 예약 작업에 붙여넣으세요.

**Q. 직원을 바꾸고 싶어요.**
사무실 위쪽 **직원 채용** 버튼을 누르면 언제든 바꿀 수 있어요.

**Q. 내 정보는 어디에 저장되나요?**
내 claude.ai 사무실 안에만 저장돼요. 이 깃허브에는 아무 정보도 올라오지 않아요.
돈·건강 같은 내용은 나만 볼 수 있게 저장돼요.

**Q. 가족이나 동료도 볼 수 있나요?**
사무실을 공유하면 손님으로 들어와 일정을 보고 약속을 요청할 수 있어요. 승인은 나만 해요.

**Q. 깃허브 페이지에서 바로 열면 안 되나요?**
화면은 보이지만 저장과 AI 기능은 움직이지 않아요. 꼭 claude.ai에 올려서 쓰세요.
