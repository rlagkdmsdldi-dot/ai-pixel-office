# AI 픽셀 오피스 🏢

AI 직원들이 픽셀 사무실에서 일하는 **개인 비서 대시보드**입니다.
일정·할 일·결재함·팀별 업무·회의실 대화를 한 화면에서 보고, 직원에게 말을 걸면 Claude가 실제로 일을 정리해 줍니다.

> 실제로 매일 쓰던 오피스를 개인 정보를 걷어 내고 누구나 쓸 수 있는 템플릿으로 공개한 것입니다.

## 무엇을 할 수 있나요
- 🧑‍💼 **필요한 직원만 채용**: 처음 열면 직원 후보 26명(회사·대학원·가정·자기계발·블로그·N잡 6개 팀) 중에서 골라요. '회사원', '블로그 운영' 같은 추천 묶음도 있어요. 김비서는 기본으로 함께해요.
- 🤖 **직원별 업무 자동화**: 직원 카드에 "매주 월요일 9시에 이번 주 일정 정리해줘"처럼 한 줄로 쓰면, Claude가 언제·무엇을·어디서 가져올지 정리해서 보여 주고 맡길 수 있어요.
- 🔗 **구글 연동(읽기 전용)**: claude.ai에 연결한 구글 캘린더·Gmail·구글 드라이브를 직원들이 읽어서 자동 업무에 써요. 메일 발송·삭제, 일정 변경은 하지 않아요.
- 📅 일정·할 일·결재함(나중에 보기/스누즈 포함), D-day 알림
- 💬 회의실: 직원끼리 일정을 보고 수다·통화·보고를 주고받는 연출
- 📚 자격증·시험 준비: 시험 날짜만 넣으면 30일 플랜, D-day, 복습 퀴즈가 자동으로 맞춰짐
- ✍️ 블로그: 주제 후보 → 초안 → 검수 → 발행 준비 (발행은 직접)
- 👥 손님 모드: 가족·동료가 들어와 일정 확인, 약속 요청 (승인은 대표만)

## 이건 일반 웹사이트가 아니에요
이 페이지는 **claude.ai 아티팩트 런타임** 안에서만 제대로 돌아갑니다.
`window.claude`의 DB, Claude 호출(sample), 공유방(room), 사용자 프로필 기능을 씁니다.
GitHub Pages 등에 그대로 올리면 화면은 뜨지만 저장·AI 응답은 동작하지 않아요.

## 설치 방법 (약 5분)
1. claude.ai에서 새 대화를 열고 `index.html` 파일을 첨부합니다.
2. 이렇게 요청합니다:
   > 이 HTML을 아티팩트로 그대로 게시해줘. capabilities는 첨부한 capabilities.json대로 선언해줘.
   (`capabilities.json`도 같이 첨부하세요.)
3. 게시된 페이지를 열면 **직원 채용** 창이 떠요. 필요한 직원을 고르고 '채용하기'를 누르세요.
4. 직원을 눌러 **업무 자동화** 칸에 맡길 일을 한 줄로 쓰세요. 예시 문장을 눌러도 돼요.
5. 구글 서비스를 쓰려면 claude.ai 설정 → 커넥터에서 구글 캘린더·Gmail·구글 드라이브를 연결하고, 오피스의 **구글 연결** 버튼으로 확인하세요.
6. 지시창에 "내 일정 등록해줘", "할 일 추가해줘"처럼 말하면서 채워 나가면 됩니다.

### 내 것으로 바꾸기
- 직원은 오피스의 **직원 채용** 버튼으로 언제든 바꿀 수 있어요.
- 직원 이름·말투·팀 구성을 더 고치려면: `index.html`에서 `ALL_PEOPLE`(직원 후보 목록), `PERSONA`(말투), `TEAM`(팀), `CHATS`·`TEAMTALK`(회의실 대화) 상수를 찾아 수정
- 이름 표기 "대표님", 마스코트 "몽이": 찾아 바꾸기로 원하는 이름으로
- 시험 준비: `index.html`에서 `EXAM_CFG`를 찾아 시험 이름(`name`)과 날짜(`date`)만 바꾸면 돼요. 30일 플랜 내용은 `JP_PLAN`에서 내 교재 목차로 바꿀 수 있어요.
- 교재 암기 체크북(`JP_CB`)은 비어 있어요. **본인이 산 교재 내용으로 직접** 채우세요(저작권).
- 제일 쉬운 방법: Claude에게 "이 오피스에서 강의팀을 빼고 운동팀을 넣어줘"처럼 부탁하기

## 자동화는 언제 돌아가나요
- **사무실을 열 때**: 정해진 시각이 지난 뒤 사무실을 열면(또는 열어 둔 동안) 직원이 처리해서 보고서로 올려요. 따로 설치할 것이 없어요.
- **창을 닫아 둬도 그 시각에**: 직원 카드의 '예약 작업 문장 복사'를 눌러 Claude 앱의 예약 작업에 붙여넣으세요. `<여기에 내 오피스 주소 붙여넣기>` 자리에 내 오피스 링크를 넣으면 돼요.
- `prompts/` 폴더에도 아침 회의·퇴근 보고·뉴스 정리 예약 작업 예시가 있어요.

## 개인 정보·안전 원칙
- 돈·건강 같은 개인 정보는 private으로 저장하고 손님에게 보이지 않아요(가족 관리자 권한 제외).
- AI가 외부로 메일·메시지를 보내거나 글을 발행하지 않도록 프롬프트에 막아 두었어요.
- 이 저장소에는 실제 개인 데이터·연락처·캘린더 ID가 없습니다. 데이터는 각자의 아티팩트 DB에만 저장됩니다.
